# 22 — Creative Concepts, Hooks & Storyboard Templates

Concepts for **System B** — the property videos we produce for customers. System A (our own
marketing content) is in [29](29-content-calendar.md) and [30](30-advertising-packages.md).

Every concept is governed by [26](26-property-accuracy-rules.md). Where a concept has a specific
way of going wrong, that is stated in its **Accuracy risks** row — this is the field that
distinguishes a usable production system from a mood board.

---

## The 10 concepts

### VC-1 — "The Walk Through"
| Field | |
|---|---|
| **Audience** | Any guest. The default when the property's strength is its layout |
| **Objective** | Spatial comprehension — how rooms connect |
| **Assets required** | 12+ photos covering a continuous path through the property, including doorways |
| **Opening** | Front door or entry, static, 1s |
| **Shot sequence** | Entry → hall → main living space → kitchen → outdoor → bedroom → bathroom. **In the real physical order** |
| **On-screen text** | Room labels, lower third, one per shot |
| **Audio** | Light bed, or silent for the Vrbo cut |
| **Ending** | Wide of the best space, hold 1.5s |
| **CTA** | Property name + location. **No URL on the Vrbo cut** (E-05) |
| **Difficulty** | Low |
| **Cost drivers** | Shot count (10–12 clips) |
| **Accuracy risks** | **Implied adjacency.** Cutting bedroom→pool suggests they adjoin. If they don't, insert a transition or a caption |
| **Review criteria** | Room order matches the fact sheet's stated layout. No invented doorway |

### VC-2 — "One Reason"
| Field | |
|---|---|
| **Audience** | A specific guest type |
| **Objective** | Communicate one differentiator, completely |
| **Assets required** | 5–7 photos, at least 3 of the differentiating feature |
| **Opening** | The feature, close, in motion |
| **Shot sequence** | Feature close → context wide → feature in use → the space it serves → feature again, different angle |
| **On-screen text** | One sentence naming the reason, held 3s |
| **Audio** | Music or silence |
| **Ending** | The feature, wide |
| **CTA** | "Sleeps [N] · [Location]" |
| **Difficulty** | Low. **Best value per minute of work** |
| **Cost drivers** | Fewest clips of any concept |
| **Accuracy risks** | Overstating the feature. "Steps from the beach" must be a measured fact |
| **Review criteria** | The claimed reason appears verbatim on the fact sheet |

### VC-3 — "A Day Here"
| Field | |
|---|---|
| **Audience** | Couples, families; leisure stays |
| **Objective** | Trip-fit through an implied narrative |
| **Assets required** | 10+ photos across different times of day, ideally including exterior light variation |
| **Opening** | Morning light on a bed or a window |
| **Shot sequence** | Morning → coffee/kitchen → outdoor midday → afternoon interior → evening light → night |
| **On-screen text** | Time-of-day markers, minimal |
| **Audio** | Music, warm |
| **Ending** | Evening exterior or lit interior |
| **CTA** | Property name |
| **Difficulty** | Medium |
| **Cost drivers** | Needs genuine light variation in the source photos |
| **Accuracy risks** | **High.** Faking time of day by regrading a midday photo to look like sunset invents light the property may never get. A north-facing room does not get golden hour |
| **Review criteria** | Each time-of-day shot derives from a photo actually taken at that time, or is graded only within plausible range. **If in doubt, cut the shot** |

### VC-4 — "Sleeps Twelve"
| Field | |
|---|---|
| **Audience** | Groups, large families, multi-generational |
| **Objective** | Prove capacity credibly |
| **Assets required** | A photo of every bedroom and every sleeping surface |
| **Opening** | The largest shared space, full |
| **Shot sequence** | Shared space → each bedroom in turn, counted on screen → bathrooms → the dining table with all chairs |
| **On-screen text** | Running count: "Bedroom 1 · 2 people" |
| **Audio** | Music |
| **Ending** | The full dining table |
| **CTA** | "Sleeps [N] · [N] bedrooms · [N] bathrooms" |
| **Difficulty** | Medium |
| **Cost drivers** | Shot count scales with bedrooms |
| **Accuracy risks** | **Highest of any concept.** Capacity misrepresentation is a named refund trigger (E-12). Sofa beds and bunk rooms must be **shown as what they are**, not glossed |
| **Review criteria** | On-screen count reconciles exactly to the fact sheet. Every sleeping surface is visible. **Hard reject if the count is off by one** |

### VC-5 — "The View From Here"
| Field | |
|---|---|
| **Audience** | Guests choosing on scenery |
| **Objective** | Show the actual outlook |
| **Assets required** | Window/balcony photos taken from inside, looking out |
| **Opening** | Interior, window out of focus, pulling to the view |
| **Shot sequence** | Interior → window → view → back to interior with the view visible |
| **On-screen text** | Direction and what is visible, factually |
| **Audio** | Natural or light bed |
| **Ending** | Wide with window and room together |
| **CTA** | Location |
| **Difficulty** | Medium |
| **Cost drivers** | Low |
| **Accuracy risks** | **Extreme.** Generating or enhancing a view is the single most damaging alteration available. Adding sea to a window that shows rooftops is exactly the enforcement case in E-11 |
| **Review criteria** | **Every frame of view content traces to a supplied photograph.** No generative extension of a view. **Hard reject, no exceptions** |

### VC-6 — "Before You Ask"
| Field | |
|---|---|
| **Audience** | Guests with practical doubts; strong for accessibility, parking, pets |
| **Objective** | Answer the question that stops a booking |
| **Assets required** | Photos of the specific practical features |
| **Opening** | Text question on a plain frame: "Is there parking?" |
| **Shot sequence** | Question → the answer, shown → the next question → shown |
| **On-screen text** | The questions, large |
| **Audio** | Music or silence |
| **Ending** | "Anything else? Ask." |
| **CTA** | Contact (social cut only — **not** on the Vrbo cut, E-05) |
| **Difficulty** | Low |
| **Cost drivers** | Low |
| **Accuracy risks** | Answering a question the fact sheet doesn't cover. **Every answer must be a fact-sheet field** |
| **Review criteria** | One-to-one mapping from each on-screen answer to a fact-sheet line |

### VC-7 — "The Neighbourhood"
| Field | |
|---|---|
| **Audience** | Guests choosing on location |
| **Objective** | Place the property in its surroundings |
| **Assets required** | Property photos **plus** area photos the customer holds rights to |
| **Opening** | Exterior of the property |
| **Shot sequence** | Property → street → nearby landmark → back to property |
| **On-screen text** | Walk/drive times, **measured, from the fact sheet** |
| **Audio** | Music |
| **Ending** | Property exterior |
| **CTA** | Location |
| **Difficulty** | Medium |
| **Cost drivers** | Often blocked by missing area photos we can license |
| **Accuracy risks** | **Two.** (1) **Rights** — stock or scraped area imagery is a licensing problem ([38](38-rights-and-security.md)). (2) **Vrbo caps area footage at ~20%** (E-06), so the Vrbo cut needs a different ratio from the social cut |
| **Review criteria** | Every area image is rights-cleared. Vrbo cut: area footage ≤20% of runtime, timed |

### VC-8 — "Off Season"
| Field | |
|---|---|
| **Audience** | Shoulder and off-season guests |
| **Objective** | Sell the property in its quiet months |
| **Assets required** | Photos with off-season character — a lit fire, rain on glass, bare trees |
| **Opening** | Warm interior detail |
| **Shot sequence** | Fire/warmth → window with weather → interior comfort → a cosy corner |
| **On-screen text** | Seasonal framing, factual |
| **Audio** | Music, slow |
| **Ending** | Wide interior, lit |
| **CTA** | Property name |
| **Difficulty** | Low |
| **Cost drivers** | Low |
| **Accuracy risks** | Implying a wood burner that is decorative, or heating that does not exist. **Verify heating on the fact sheet** — a cold guest in January is a refund |
| **Review criteria** | Heating and fireplace status confirmed |

### VC-9 — "The Detail Reel"
| Field | |
|---|---|
| **Audience** | Design-led guests; premium properties |
| **Objective** | Convey quality through texture |
| **Assets required** | 8+ close-up photos: materials, fittings, textiles |
| **Opening** | The most tactile detail |
| **Shot sequence** | 6–8 close details, consistent rhythm, one wide to establish |
| **On-screen text** | Minimal or none |
| **Audio** | Music-led |
| **Ending** | One wide |
| **CTA** | Property name |
| **Difficulty** | Low |
| **Cost drivers** | Very low. **The safest concept for generative motion** — close textures hide the geometry artifacts that wreck architectural shots |
| **Accuracy risks** | **Low, and this is the point.** Details are real objects; no layout is implied. But close-ups can flatter a tired property overall — include one honest wide |
| **Review criteria** | At least one wide establishing shot. No invented objects |

### VC-10 — "Arrival"
| Field | |
|---|---|
| **Audience** | **Booked guests**, not prospects (E-02 — sent in the Airbnb message thread) |
| **Objective** | Reduce arrival friction and check-in messages |
| **Assets required** | Photos of the street, door, lock, parking, key location |
| **Opening** | The street approach |
| **Shot sequence** | Street → building exterior → parking → door → lock/keybox → entry |
| **On-screen text** | Practical instructions, large, legible |
| **Audio** | Voice or captions |
| **Ending** | "See you soon" |
| **CTA** | None |
| **Difficulty** | Low |
| **Cost drivers** | Very low |
| **Accuracy risks** | **Lowest of all concepts** — it is purely functional and makes no marketing claim. Only risk is showing a lock code |
| **Review criteria** | **No visible codes, keys, or security details.** Directions match the fact sheet |

**Note on VC-10:** it is the least glamorous concept and possibly the most commercially
interesting. It is the only legitimate Airbnb-channel deliverable (E-02), carries near-zero
accuracy risk, and solves a problem every host actually has — repetitive check-in messages.
[36](36-retention-plan.md) treats it as a candidate repeat purchase.

## 30 hooks

Opening 1–2 seconds. Grouped by mechanism.

**Fact-forward (1–6)**
1. "Sleeps 12. Here's where." · 2. "Eight minutes to the beach. Timed." · 3. "Three bedrooms, two
of them bunk rooms." · 4. "Two flights of stairs. No lift." · 5. "40 seconds to the water."
6. "Two bathrooms, both with windows."

**Question (7–12)**
7. "Where does everyone sleep?" · 8. "Is there parking?" · 9. "Can you actually work here?"
10. "What's the walk to the beach?" · 11. "Will the dog be OK?" · 12. "Does the kitchen work for
twelve?"

**Feature-first (13–18)**
13. "The table seats twelve." · 14. "That window is four metres." · 15. "The fire is real."
16. "The desk faces the window." · 17. "The garden is enclosed." · 18. "Every bedroom has a door
that shuts."

**Sensory (19–23)**
19. Silent 1s hold on morning light. · 20. Rain on glass, natural sound. · 21. A fire catching.
22. A door opening onto the view. · 23. Steam from a kettle in a cold kitchen.

**Contrast (24–27)**
24. "Not a hotel." · 25. "Small. On purpose." · 26. "No sea view. Here's what there is instead."
27. "Nothing here is new."

**Direct address (28–30)**
28. "If you're travelling with a dog, watch this one." · 29. "For the group who always argues
about beds." · 30. "If you work while you travel."

**Rules for hooks:** must be true and fact-sheet-verifiable. Never a question the video does not
answer. #26 and #27 are deliberately anti-promotional — honest negatives outperform generic
praise in a feed where everything is praise, and they pre-qualify the guest.

## 10 storyboard templates

Reusable structures. Timings are targets for the 9:16 social cut; the Vrbo cut extends to 45–60s.

| # | Template | Structure | Best for |
|---|---|---|---|
| **ST-1** | Linear walkthrough | Entry (2s) → 6 spaces (3s each) → wide hold (2s) | VC-1 |
| **ST-2** | Single-feature deep | Feature close (2s) → context (3s) → in-use (3s) → served space (3s) → feature wide (3s) | VC-2 |
| **ST-3** | Day arc | 6 beats × 3s, morning to night, warming grade | VC-3 |
| **ST-4** | Counted inventory | Establish (2s) → N rooms × 2.5s with running count → total card (2s) | VC-4 |
| **ST-5** | Reveal | Interior tight (2s) → pull to window (3s) → view (4s) → return wide (3s) | VC-5 |
| **ST-6** | Q&A | 4 × (question card 1.5s + answer shot 2.5s) | VC-6 |
| **ST-7** | Out and back | Property (3s) → street (2s) → landmark (3s) → property (3s) | VC-7 |
| **ST-8** | Mood loop | 5 details × 3s, no text, seamless first-to-last frame | VC-8, VC-9, and **the silent web loop** |
| **ST-9** | Texture rhythm | 8 × 2s close details + 1 × 4s wide | VC-9 |
| **ST-10** | Instructional | Street (2s) → door (2s) → lock (3s) → entry (3s), instruction text throughout | VC-10 |

**ST-8 doubles as the silent 8–12s web loop deliverable** — one storyboard producing two package
items is exactly the kind of reuse the financial model needs ([15](15-financial-model.md) §3).

## Production metadata — recorded for every video

Generative output is nondeterministic. **We never promise exact reproduction.** We preserve the
selected files instead, and record enough to explain how they were made.

| Field | Why |
|---|---|
| Concept ID (VC-N) and storyboard ID (ST-N) | Traceability |
| Model name and version, per clip | Vendor terms and behaviour change; E-21–E-23 |
| Settings: seed (if exposed), resolution, duration, motion strength | Partial reproducibility |
| Source photo filename and hash, per clip | **Provenance — proves what the motion derived from** |
| Attempts made, attempts accepted | Feeds the A-09 cost measurement |
| Accuracy review outcome and reviewer | [26](26-property-accuracy-rules.md) |
| Quality score and any waived items | [27](27-quality-rubric.md) |
| Music track ID and licence reference | E-18 |
| Final selected files, archived | **The deliverable of record** |

**The commitment we make:** we keep the files we selected and can show which photograph each
clip came from. **We do not claim we could regenerate an identical clip**, because with
nondeterministic models we could not, and promising it would be a claim we cannot honour.
