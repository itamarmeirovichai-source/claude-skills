# 30 — Advertising Packages

Six ad concepts and the campaign structure. Experiment rules and stopping conditions:
[31](31-experiment-design.md). Claims: [21](21-claim-register.md).

## Rule before anything else

**A visible ad is not a successful ad. A long-running ad is not a winning ad.** Ad libraries show
what is running, not what is profitable. We cannot see any competitor's cost per acquisition, and
we will not infer it from creative polish or spend longevity
([11](11-competitor-analysis.md)).

## The six concepts

Each targets a different buyer-and-situation pair, so the test measures *message*, not
execution variance.

### AD-1 — "Your photos already contain a video" *(the baseline)*
| Field | |
|---|---|
| Target buyer | S2 owner, 2–5 units |
| Buying situation | Has good photography, has posted none of it as video |
| Angle | Latent asset — you already own the raw material |
| Opening frame | A grid of still photos, one begins to move |
| Script | *(text on screen)* "You paid for these photos." / "They've been sitting in a folder." / "Seven videos. Three to five days." / "From the photos you already have." |
| Visual sequence | Photo grid → one animates → three formats appear side by side → file list |
| On-screen text | As script |
| Audio | Light bed, sound-off legible |
| Primary copy | "Short property videos made from photos you already own. No site visit, nothing to schedule around guests. Sized for Instagram, your booking site, Google and Vrbo." |
| Headline | Your photos already contain a video |
| CTA | See examples |
| Landing page | Illustrative library ([34](34-website-specification.md)) |
| Assets | Illustrative property, 12 photos |
| **Claim check** | ✅ All permitted. No outcome claim |

### AD-2 — "Airbnb won't let you post video"
| Field | |
|---|---|
| Target buyer | Anyone who has searched for Airbnb listing video |
| Buying situation | Actively confused about a thing the category misrepresents |
| Angle | Pure education. **The only ad whose first job is to correct a false belief** |
| Opening frame | Text on plain background: "Airbnb won't let you post video." |
| Script | "Airbnb won't let you post video." / "Not on your listing. Photos only." / "Vrbo will. So will Instagram, your own site, and Google." / "That's what these are for." |
| Visual sequence | Text card → Airbnb photo-only UI *(generic, no branding — E-13)* → the four channels → files |
| Audio | None. Captions carry it |
| Primary copy | "Airbnb doesn't accept host-uploaded video on listing galleries. It's photos only. Video still works for a rental — just everywhere else. We make the files for everywhere else." |
| Headline | Airbnb won't let you post video |
| CTA | See where video actually works |
| Assets | Text-led, cheap to produce |
| **Claim check** | ✅ E-01. **No Airbnb logo, no Bélo, no implied endorsement** (E-13) |

**The highest-variance concept.** It may be the best-performing ad in the set because it is the
only one saying something the reader does not already know, or it may confuse cold traffic that
has not framed the problem that way. This uncertainty is exactly why it is tested.

### AD-3 — "The accuracy one"
| Field | |
|---|---|
| Target buyer | S2/S3 who has heard of platform enforcement |
| Buying situation | Considering AI media and uneasy about it |
| Angle | Risk. **Tests A-02 directly** |
| Opening frame | A clip with an obviously warped doorframe, then a red REJECTED stamp |
| Script | "This one didn't ship." / "The doorframe bends." / "So does the trust." / "Every video gets checked against the property before you see it." |
| Visual sequence | Rejected clip → checklist on screen → clean clip → files |
| Audio | Light bed |
| Primary copy | "Platforms can require hosts to remove listing media that's been altered to add things a property doesn't have. So we check every video against the property before delivery, against a checklist we publish." |
| Headline | A property video that shows the property that exists |
| CTA | Read the checklist |
| Landing page | **The published accuracy checklist** ([26](26-property-accuracy-rules.md)) |
| **Claim check** | ⏳ The E-11 phrasing requires **V-0 verification** before this ad runs |

**AD-1 vs AD-3 is the central test of [12](12-positioning.md)** — does the concrete-deliverable
message or the risk message acquire cheaper leads? If AD-3 loses badly, A-02 fails and accuracy
demotes from lead message to trust-builder.

### AD-4 — "Show owners what you'd do for their property"
| Field | |
|---|---|
| Target buyer | **S3 property manager** |
| Buying situation | Pitching for a new owner contract |
| Angle | **Owner acquisition, not guest acquisition** — a different budget line (E-30) |
| Opening frame | A portfolio grid of property videos, uniform look |
| Script | "You're pitching for their property." / "So is everyone else." / "Show them the marketing you'd actually do." / "Fourteen units. One look. One schedule." |
| Visual sequence | Grid → one property's file set → consistent branding across three properties |
| Audio | Light bed |
| Primary copy | "When you pitch a homeowner, the other managers show a spreadsheet. Consistent video across your portfolio, made from photography you already hold. Pilot of three before anyone talks volume." |
| Headline | Show owners the marketing you'd do for their property |
| CTA | See the pilot |
| Landing page | PM-specific page |
| **Claim check** | ✅ No outcome claim. "Helps you win owners" would **not** be permitted; "show them" is |

**The most strategically interesting concept.** If it works, it reaches a budget line that is not
competing with guest-acquisition spend, targets the highest-margin segment, and sells against a
need with no booking-causation problem at all.

### AD-5 — "No site visit"
| Field | |
|---|---|
| Target buyer | S2/S3 with occupied units |
| Buying situation | Booked solid, cannot empty a property for a shoot |
| Angle | The structural gap ([11](11-competitor-analysis.md) §3) |
| Opening frame | A calendar full of bookings |
| Script | "Booked through September." / "So when does the videographer come?" / "They don't." / "Send photos. Get videos." |
| Visual sequence | Calendar → crossed-out camera → upload → files |
| Audio | Light bed |
| Primary copy | "A videographer needs an empty property and a day in your calendar. We need your photos. No visit, no turnover gap, no travel fee." |
| Headline | Nothing to schedule around guests |
| CTA | See examples |
| **Claim check** | ✅ Process facts only. Travel fees are public (E-31) |

### AD-6 — "I won't promise you bookings"
| Field | |
|---|---|
| Target buyer | Skeptical, has been pitched before |
| Buying situation | Burned by a marketing vendor |
| Angle | **Refusal as the hook** |
| Opening frame | Text: "I won't promise you bookings." |
| Script | "I won't promise you bookings." / "Nobody can back that up." / "Here's what I will promise:" / "Seven files. Five days. Checked against your property." |
| Visual sequence | Text → file list → checklist → delivery folder |
| Audio | None |
| Primary copy | "There's no credible evidence that property video causes bookings. Anyone quoting you a number is quoting their own marketing. What we commit to is the files, the formats, the accuracy review and the date." |
| Headline | I won't promise you bookings |
| CTA | See what is promised |
| **Claim check** | ✅ The strongest-permitted claim in the register, because it is a refusal |

**Highest-variance after AD-2.** In a feed of guarantees, a refusal is differentiated. It may
also read as weak to a buyer who wants confidence. Genuinely unknown, cheap to find out.

## Campaign structure

**Do not fragment a small budget.** Six concepts across six campaigns at $300 total gives each
$50 and none enough data to mean anything.

| Element | Setting | Why |
|---|---|---|
| **Structure** | **1 campaign → 1 ad set → 6 ads** | Consolidated budget, platform distributes. At this budget, splitting ad sets buys noise |
| Objective | Leads or Traffic-to-form | Not Awareness. Not Engagement |
| Optimisation event | **Qualification form submission** | The cheapest event genuinely correlated with revenue |
| Geography | 2–3 US states with high STR density, chosen from a real listing-density source | Keeps CPM sane and makes the sample coherent |
| Audience hypothesis | Broad, age 30–65, interests around vacation rental hosting and property management. **Let the platform optimise** | At this budget, narrow targeting raises CPM without improving quality |
| Placements | Automatic | Manual selection at this budget reduces delivery |
| **Budget** | **$300 total test, $20/day for 15 days** | [31](31-experiment-design.md) |
| **Spending control** | **Account spending limit set to $300 BEFORE launch** | **E-34, D-09 — daily budgets are not caps.** Daily × 1.75 possible in a day; 7× daily over a rolling week |
| Schedule | Continuous. No dayparting | Not enough data to justify it |
| Exclusions | Existing customers; anyone who has submitted the form | Avoid paying to reach people we have |
| Tracking | UTM per ad + a source field on the form | Platform-reported conversions are **not** the source of truth ([41](41-measurement-definitions.md)) |
| Naming | `[YYYYMM]_[objective]_[audience]_[AD-N]_[variant]` | Consistency for later analysis |

### Budget behaviour — the thing that must be verified

**E-34 is grade B and describes a control that protects real money.** Before any spend:

1. Read Meta's own documentation on daily budgets and account spending limits (V-0).
2. Set the account spending limit to the experiment's **maximum acceptable loss**, not to the
   intended spend.
3. **Never describe a daily budget as a hard cap** in any plan or to any partner.

With a founder unavailable 8–10 hours at a stretch (A-15), the account spending limit is the
only control that works while nobody is looking.

## Claim verification before launch

| Ad | Status | Blocked on |
|---|---|---|
| AD-1 | ✅ Ready | — |
| AD-2 | ✅ Ready | Visual must contain **no Airbnb branding** (E-13) |
| **AD-3** | ⏳ **Blocked** | V-0: read Airbnb's Ground Rules/Content Policy directly to confirm E-11 phrasing |
| AD-4 | ✅ Ready | — |
| AD-5 | ✅ Ready | — |
| AD-6 | ✅ Ready | — |

**AD-3 does not run until E-11 is verified from the primary source.** Running an ad that
describes another company's enforcement policy on grade-B evidence is exactly the kind of
avoidable false claim this system exists to prevent.

## Acceptance criteria

- [ ] Account spending limit set before the first impression
- [ ] All six ads pass the [21](21-claim-register.md) check
- [ ] AD-3 held until V-0 completes
- [ ] No Airbnb, Vrbo, Google or Meta branding in any creative
- [ ] Every ad has a UTM; every form has a source field
- [ ] Cost per **qualified** lead computed per ad, from our own records — not from the platform's
      reported conversions
