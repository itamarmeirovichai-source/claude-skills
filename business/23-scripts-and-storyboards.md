# 23 — Scripts, Prompt Library & Production Guides

Companion to [22](22-creative-concepts.md). All scripts use the illustrative archetypes from
[10](10-traveler-decisions-and-property-messaging.md) — **A** coastal cottage, **B** city studio,
**C** mountain lodge, **D** design loft, **E** barn conversion. **None is a real property.**

Bracketed `[FACT: x]` marks a value that must come from the signed Property Fact Sheet. **If the
fact sheet does not contain it, the line is cut — it is never estimated.**

## Prompt library

For image-to-video generation. **Principle: prompts describe camera behaviour, never content.**
A prompt that describes content invites the model to invent it.

### The safe pattern
```
[CAMERA MOVE], [SPEED], subtle, photorealistic, preserve original architecture
and geometry, no new objects, no change to layout, no added light sources,
maintain straight lines, static subject
```

### Approved camera moves

| ID | Prompt fragment | Use | Risk |
|---|---|---|---|
| **P-01** | `slow push in, very subtle, 5% zoom, preserve geometry` | Establishing, details | Low |
| **P-02** | `slow pull back, very subtle, preserve geometry` | Reveal into wide | Low |
| **P-03** | `gentle parallax, camera drifts left 3%, static subject` | Interiors | **Medium — straight lines warp at the frame edge** |
| **P-04** | `slow vertical tilt up, subtle, preserve verticals` | Tall windows, high ceilings | Medium |
| **P-05** | `shallow handheld float, minimal, no rotation` | Detail shots | Low |
| **P-06** | `subtle atmospheric motion in soft furnishings only, architecture static` | Textiles, curtains | Low |
| **P-07** | `firelight flicker on existing fire only, no new light sources` | VC-8 | **Medium — models add glow** |
| **P-08** | `water surface motion only, shoreline and structures static` | Pools, coastal | **High — models invent shoreline** |

### Forbidden prompt content

**Never** ask a model to: add, remove, extend or change a view · add furniture, decor or
appliances · change room dimensions or proportions · add light sources or windows · add people or
animals · change weather or time of day beyond a grade · clean, tidy or repair · extend a room
beyond the photo's frame · "make it look bigger/brighter/more luxurious."

Each of these maps directly to the enforcement language in E-11. A prompt containing any of them
is a defect, whether or not the output looks fine.

### Prompt hygiene
- One photo, one clip. **Never chain outputs** — drift compounds invisibly.
- Generate 5s; use 2–3s. The first and last frames are where artifacts live.
- Motion strength low. **If a clip needs high motion to be interesting, the photo is wrong for
  the shot.**
- Log every attempt with its prompt ([22](22-creative-concepts.md) §Production metadata).

## Shot selection guide

**Choosing 12 photos from 40.** This is the judgment a DIY tool does not provide and the main
thing a customer is paying for ([12](12-positioning.md) §2).

**Include, in priority order:**
1. One shot that establishes what the property *is* — usually exterior or main living space.
2. The differentiator named in the brief, from at least two angles.
3. Every bedroom, if capacity is part of the message (VC-4: **all of them, no exceptions**).
4. The kitchen — disproportionately decisive for self-catering guests.
5. One bathroom.
6. Outdoor space, if it exists.
7. Two or three details that convey material quality.
8. One honest wide of the *least* flattering necessary space, if the message implies it exists.

**Exclude:** anything with visible clutter, personal items, other guests, or reflections showing
the photographer · near-duplicates · anything under 1500px · anything whose light contradicts the
adjacent shot · anything showing a feature no longer present · **anything the customer cannot
confirm is currently accurate.**

**The ordering rule:** follow the real physical path. A viewer builds a mental map, and a cut
that teleports breaks comprehension — which is the one job video does better than photos
([10](10-traveler-decisions-and-property-messaging.md)).

## Caption guide

| Rule | Detail |
|---|---|
| Always burned in | Sound-off default (E-33) |
| Position | Lower third, above the platform UI safe area |
| Length | ≤6 words per card |
| Duration | Minimum 1.2s, or 0.3s per word, whichever is longer |
| Contrast | White on a 40% scrim. Never text directly on a bright wall |
| Font | One sans-serif, two weights maximum |
| Facts | Every number traces to the fact sheet |
| **Vrbo cut** | **No phone numbers, URLs, booking links, or contact details anywhere in frame** (E-05) |
| Deliver | `.srt` alongside, for platform-native captions |
| Accessibility | Captions describe spoken content; on-screen text is not a substitute for it |

## Sound guide

| Element | Rule |
|---|---|
| Music | Licensed via [15](15-financial-model.md) / E-18 only. **Never editor-stock music** (E-24) |
| **Vrbo cut** | **No added music at all** (E-04). Natural sound, or silence |
| Web loop | Silent, always. Autoplay contexts are muted |
| Levels | Music −18 to −14 LUFS; duck under any voice |
| Voiceover | Optional; **AI voice must be disclosed as synthetic** (D-13) |
| Natural sound | Only if the customer supplied genuine audio from the property. **Never generate ambience** — invented ocean sound over a rooftop view is an accuracy failure with a soundtrack |
| Sync | Cut on the beat where it helps comprehension, not because it can be done |
| Ending | Fade, never a hard stop on a loop |

## Export checklist

Run per file before delivery.

- [ ] Correct aspect ratio and resolution: 9:16 1080×1920 · 1:1 1080×1080 · 16:9 1920×1080
- [ ] Duration within the package spec ([14](14-offer-specification.md))
- [ ] H.264, MP4, yuv420p (maximum compatibility)
- [ ] Captions burned in where specified; `.srt` exported
- [ ] Safe areas respected — nothing critical in the outer 10%
- [ ] Audio levels checked; **loop and Vrbo cut are silent/music-free**
- [ ] **Vrbo cut:** 15–60s, no music, no contact details in frame, area footage ≤20% (E-03–E-06)
- [ ] **GBP cut:** ≤30s, 1080p, **file size under 75MB** (E-08) — check the actual file
- [ ] Loop: first and last frames match
- [ ] Filename follows the delivery convention
- [ ] Played back on a phone at arm's length. **If a caption is unreadable there, it fails**
- [ ] Watched once with sound off, once with sound on
