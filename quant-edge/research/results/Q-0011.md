## Disclosures and implementation notes (fixed before the OOS read)

- 'Previous trading day' = latest XNYS session <= d: Friday (or the last session before it) for Sunday evenings, d itself for Mon-Thu evenings (the pre-halt close of the same futures trading day).
- Eligible evening for the scale s = passes the evening definition (Sun-Thu, XNYS holiday filter on d and d+1, all 18:00..18:10 bars) and C exists; for sigma additionally the 18:11 bar exists. Both histories include evenings failing the FTMO-day filter. EWMA = pandas ewm(com=60, min_periods=40): mean of M^2 (s), std of r (sigma), read at the last eligible evening before d.
