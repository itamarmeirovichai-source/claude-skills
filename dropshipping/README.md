# AI Dropshipping Research Program

Research program run under `deep-research-protocol.md` with the dropshipping overlay (iron laws 1–19).
Resume protocol (overlay §11.3): read, in this order and nothing more, `CHECKPOINT.md`, `DECISION-MEMO.md`, `registry.md`, `ledger.md`. Then do the "exact next unit" named in the checkpoint.

| File | What it is |
|---|---|
| `CHECKPOINT.md` | Where the program is, the exact next unit, half-done work, open operator questions |
| `DECISION-MEMO.md` | Current answer, in Hebrew; also the PR description |
| `phase0/FRAME.md` | Frozen Phase 0 frame: goal arithmetic, constraint audit, milestone ladder, council, stop conditions |
| `phase0/goal_math.py` | The arithmetic, with every input tied to a source id |
| `registry.md` | Every hypothesis (P-/A-/C-/O-/L-) with bar, kill condition, verdict |
| `reads.log` | Append-only log of every out-of-sample read |
| `ledger.md` | Every dollar: external capital (cap $2,000) and reinvested earnings, two columns that never mix |
| `sources.md` | Every fetched source with URL, access date, the line relied on, quality, expiry |
| `curriculum.md` | One row per source studied: what we now do differently, expected effect, cost |
| `tools.md` | Tool inventory, vetting, approvals |
| `automation.md` | What is automated, with caps, kill switches and review windows |
| `runbooks/` | One runbook per manual process |
| `results/` | One file per hypothesis verdict |
| `sweeps/` | One file per research sweep |
| `WORK-LOG.md` | What happened, in order |
