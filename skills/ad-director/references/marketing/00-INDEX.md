# 00-INDEX · every marketing doc in one page

Read this first, then open only the docs the task needs. Updated 2026-10-09. **Whoever adds or supersedes a doc updates its row here in the same commit** (vxo-daily step 6).

How to use it:
- **LESSONS wins over every doc** (`research/ai-video-reels/lab/LESSONS.md`). When a doc and LESSONS disagree, follow LESSONS and use the conflict table at the bottom.
- `unv` = how many `[unverified]` tags the doc carries. Treat any number from a high-`unv` doc as directional, and **never paste one into a client message** without re-checking it live.
- Docs 00–40 were written 2026-10-07/08, before the owner's 2026-10-09 rules on hard cuts, hooks and punchlines. Where they say "one continuous take, no cuts" or "no comedy", that is superseded for action and story films (see the conflict table).
