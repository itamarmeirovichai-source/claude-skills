## תקציר

1. **עלות כלים לרילס גמור של 30 שניות** (בסגנון @edbert_yienson / Genjutsu) נעה בין **~$10 (₪30)** במסלול Kling 3.0 זול, ל-**$28–53 (₪85–165)** במסלול הפרימיום Seedance 2.5 1080p ב-Higgsfield. ב"חלונות Unlimited" של Higgsfield (7–33 יום לדגם חדש) העלות השולית יכולה לרדת כמעט לאפס — וזה בדיוק הזמן שבו הקריאייטורים מהמקור פרסמו.
2. **יחס ניסיונות (retry ratio) ריאלי: 3 יצירות לכל שוט שימושי, ~25% מהקליפים נכנסים לעריכה הסופית**, ובממוצע משתמשים רק ב-5 שניות מתוך קליפ של 15 שניות ([invideo](https://invideo.io/faq/how-do-you-budget-for-failed-ai-video-generations-and/)). Kling מדווחים 3–5 ניסיונות לקליפ ([eesel](https://eesel.ai/blog/kling-ai-pricing)). **תמחרו תמיד ×3 מעלות "הדור האחד".**
3. **מלכודת הקרדיטים:** תוכנית Higgsfield Plus (1,200 קרדיט) מספיקה ל**כ-1–1.5 רילסים פרימיום בחודש בלבד** ב-1080p. מי שמייצר בכמות חייב: (א) לעבוד בטיוטות 480p ולרנדר 1080p רק למנצחים, (ב) לערבב דגמים (Kling ל-B-roll, Seedance ל"שוט הגיבור"), (ג) לנצל חלונות Unlimited, (ד) לשקול Dreamina (Seedance 2.5 ב-$0.035–0.047 לשנייה ב-720p).
4. **זמן עבודה:** מתחילים — 2–4 שעות לרילס; מקצוענים עם תבנית — 25–60 דקות לרילס UGC של 15–25 שניות ([betonai](https://betonai.net/how-much-ai-video-freelancers-actually-make-in-2026-real-income-data-across-kling-runway-sora-and-veo-6-niches-with-pricing-tables/)). לרילס קולנועי מרובה-שוטים כמו במקור: **3–5 שעות בהתחלה, 1.5–2.5 שעות אחרי 10 רילסים**.
5. **שכר שעתי בפועל:** ב-₪1,000 לרילס ו-3 שעות עבודה ≈ **₪286 לשעה**; ב-₪2,000 ו-3 שעות ≈ **₪600 לשעה**; ב-₪500 ו-5 שעות (מתחיל) ≈ **₪71 לשעה** — כלומר תמחור נמוך + חוסר תבנית = שכר של עבודה סטודנטיאלית.
6. **שלושה תרחישים חודשיים (מודל מלא בסעיף 6):** תחביב — רווח ~₪1,190 ב-24 שעות (₪49/שעה); הכנסה צדדית — ~₪8,700 ב-55 שעות (₪159/שעה); סוכנות — ~₪31,400 רווח לבעלים ב-90 שעות שלו + פרילנסרים (₪349/שעה, מרווח 62%).
7. **צוואר הבקבוק אינו הכלים אלא מכירות ותבנית.** עלות כלים היא 3–10% מההכנסה בתרחישים הצדדי/סוכנות. מה שקובע רווח: מחיר לרילס, אחוז ניצול תבנית (prompt templates + project files), ומספר ריטיינרים.
8. **SOP מוכן** (סעיף 3), **מבנה תיקיות + לוג פרומפטים** (סעיף 4), **שבוע עבודה באצוות** (סעיף 4.3), **ציוד** (סעיף 5), **הרחבה עם פרילנסרים** (סעיף 7) ו-**KPIs** (סעיף 8).

### 3.1 טמפלט Prompt expansion (להעתקה ל-Claude)

```
You are a commercial film director. Convert my shot list into ONE Seedance 2.5 multi-shot prompt.
Rules:
- Output format: [00:00-00:02] ... one line per shot, total 15s.
- Each line: shot size, camera move, lens (e.g. 35mm anamorphic), subject action, lighting, mood.
- Reference the uploaded assets as @Image1 (character), @Image2 (product), @Video1 (source take) exactly.
- Keep the character identical across shots: same face, outfit, hair.
- No on-screen text, no logos other than @Image2.
- End with a global style line: "Shot on ARRI Alexa 35, Kodak 500T grain, 9:16 vertical, cinematic color grade."
Shot list:
<paste shotlist.md>
```

### 3.2 צ'קליסט QA (להדפסה)

```
[ ] Hook visible in first 1s (no logo intro)
[ ] Face consistent across all shots
[ ] Hands/fingers OK, no extra limbs
[ ] No garbled text / fake brand logos
[ ] Hebrew captions RTL, inside safe zone (top 220px / bottom 420px clear)
[ ] Audio: music licensed / native audio clean, loudness ~ -14 LUFS
[ ] CTA keyword on screen + in caption + ManyChat trigger active
[ ] AI-content label on (Instagram "AI info" / client requirement)
[ ] Client's usage rights noted in delivery email
```

## 9. המלצות פעולה מעשיות (לפי סדר)

1. **חודש 1 (תחביב, ~₪90 לחודש בכלים):** Dreamina Basic + Kling Standard + CapCut חינם. 12–20 רילסים לחשבון עצמי, כל אחד עם לוג פרומפטים. מטרה: להוריד זמן לרילס מ-5 ל-3 שעות.
2. **כשנפתח חלון Unlimited של דגם חדש:** לשדרג ל-Higgsfield Plus לחודש אחד ולייצר מלאי של 10–20 שוטים + 4–6 רילסים "ראשונים על כלי חדש" (A1: edbert פרסם יום אחרי ההשקה).
3. **חודש 2–3 (צדדי):** ManyChat Free → Pro כשעוברים 500 אנשי קשר. להוציא prompt pack ב-₪49–79 מתוך הלוג. להציע 3 "רילסים פיילוט" לעסקים מקומיים ב-₪800–1,200.
4. **תמחור:** לא לרדת מ-₪1,000 לרילס 30 שנ' (מתחת לזה השכר השעתי ≈ שכר מינימום כשסופרים מכירות ותיקונים). לבנות חבילות "Hero + 3 וריאציות".
5. **חודש 4+ (מעבר לסוכנות):** editor ראשון כשעוברים 10 רילסים לחודש; ריטיינרים עם שורת Generation budget; Higgsfield Ultra/Team.
