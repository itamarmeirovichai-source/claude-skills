```
T1 PHOTOREAL: A photorealistic [shot type] of [subject], [action or expression], set in [environment]. The scene is illuminated by [lighting description], creating a [mood] atmosphere. Captured with a [camera/lens details], emphasizing [key textures and details]. The image should be in a [aspect ratio] format.

PRODUCT: A high-resolution, studio-lit product photograph of a [product description] on a [background surface/description]. The lighting is a [lighting setup, e.g., three-point softbox setup] to [lighting purpose]. The camera angle is a [angle type] to showcase [specific feature]. Ultra-realistic, with sharp focus on [key detail]. [Aspect ratio].

NEGATIVE SPACE (for captions): A minimalist composition featuring a single [subject] positioned in the [bottom-right/top-left] of the frame. The background is a vast, empty [color] canvas, creating significant negative space. Soft, subtle lighting. [Aspect ratio].

EDIT ADD/REMOVE: Using the provided image of [subject], please [add/remove/modify] [element] to/from the scene. Ensure the change is [description of how the change should integrate].

INPAINT: Using the provided image, change only the [specific element] to [new element/description]. Keep everything else in the image exactly the same, preserving the original style, lighting, and composition.

COMPOSE: Create a new image by combining the elements from the provided images. Take the [element from image 1] and place it with/on the [element from image 2]. The final image should be a [description of the final scene].

HIGH-FIDELITY (face/logo): Using the provided images, place [element from image 2] onto [element from image 1]. Ensure that the features of [element from image 1] remain completely unchanged. The added element should [description of how the element should integrate].

360 VIEW (iterative): A studio portrait of [person] against [background], [looking forward / in profile looking right / etc.]
```
טיפים רשמיים של Google:
- **"Semantic negative prompts":** כותבים "an empty, deserted street with no signs of traffic" ולא "no cars".
- **הוראות בשלבים לסצנה מורכבת:** "First... Then... Finally...".
- **טקסט בתמונה:** קודם מייצרים את הטקסט, ואחר כך מבקשים תמונה עם הטקסט.
- **360°:** מצרפים לכל בקשה את התמונות הקודמות שנוצרו.

### 1.3 תבניות רשמיות (OpenAI gpt-image) [מתוך מדריך]
- **ריבוי תמונות:** "Reference each input by **index and description** ('Image 1: product photo… Image 2: style reference…') and describe how they interact".
- **עריכה:** "change only X" + "keep everything else the same", ו-**חוזרים על רשימת השימור בכל איטרציה**. בעריכה כירורגית מוסיפים במפורש: אל תשנה saturation, contrast, layout ו-camera angle.
- **ריאליזם:** לכלול את המילה **"photorealistic"** במפורש. מפרטי מצלמה מדויקים מתפרשים "באופן רופף", אז משתמשים בהם רק כדי לכוון מראה וקומפוזיציה.
- **אנשים:** "full body visible, feet included", "looking down at the open book, not at the camera", "hands naturally gripping the handlebars".
- **טקסט:** טקסט מילולי במירכאות או ב-ALL CAPS. מילים קשות מאייתים אות-אות (Roboverse: `spelled exactly Q-E-V-R-A`). לטקסט קטן משתמשים ב-medium או high.
- **גדלים ב-gpt-image-2:** כל רזולוציה שבה שתי הצלעות כפולות של 16, הצלע הארוכה פחות מ-3840, יחס עד 3:1, ובין 655,360 ל-8,294,400 פיקסלים. **מעל 2560×1440 התוצאה "ניסיונית".** ל-9:16: `1088x1920`, או `1440x2560` כגבול האמין [חישוב לפי הכללים].
- **ריאליזם בשילוב אדם בסצנה:** "should look like a real photograph… not an overly enhanced or cinematic movie-poster image… Avoid cinematic lighting, dramatic color grading".

### 1.4 תבנית-על לפרומפט תמונה "קולנועי" לפי סעיפים (Roboverse) [מתוך מדריך]
זה המבנה שהפיק את ה-start frames הריאליסטיים ביותר בסרטון [YT:uOrcb5HXpn8 01:40]:
```
SUBJECT — who/what, exactly one; identity from @Image1 ("identity and clothing only, never its layout"); pose, weight, gaze, micro-expression; "There is only this one person in the entire photograph."
SETTING AND BACKGROUND — place, time, physically credible objects; what is EMPTY now (for a later event in video); "Absolutely no lettering, signs, logos…"
CAMERA — body + prime lens + f-stop; camera height in meters; distance; framing ("complete head, both hands, body to mid-shin"); focus point; foreground occlusion.
LIGHT — key source + direction + Kelvin; fill (stops below key); practicals; "No lens flare, because no light source faces the lens."
SURFACE AND TEXTURE — pores, fabric weave, metal grain, dust in seams.
DELIBERATE IMPERFECTIONS — uneven crease, scuffs, asymmetric brow, hairline crack.
COLOUR PALETTE — 4–5 named colors + saturation level.
COMPOSITION — thirds placement; leave space for the motion that will happen in the video; "A single normal full-frame photograph, not a contact sheet, grid, diptych…; no written text anywhere in frame."
```
**החידוש:** בתמונת ה-start frame כבר מתכננים את התנועה של הווידאו. משאירים ריק את מה שיקרה בהמשך ("Every clear chamber is completely empty: no capsule has arrived yet") ומשאירים מקום פנוי למצלמה ("leaving room for a later small lateral camera move").
