## 9. נספח: כלים ופקודות שהשתמשתי בהם (לשחזור)

```bash
# Discover recent reels of any public IG account without login (shortcode, likes, date, caption):
curl -s -A "Mozilla/5.0" "https://www.instagram.com/<user>/embed/"   # parse '"shortcode_media":' blocks
# Download reel + metadata (likes, comments, caption):
yt-dlp --impersonate chrome -f b --write-info-json -o "%(id)s.%(ext)s" "https://www.instagram.com/reel/<ID>/"   # sleep 20s between
# Cuts (use crop when the reel is split-screen or letterboxed, else the static panel hides cuts):
ffmpeg -i in.mp4 -vf "crop=720:420:0:230,scale=320:-2,scdet=threshold=8" -an -f null - 2>&1 | grep -o "lavfi.scd.time: [0-9.]*"
# Hook strip (8 frames in first 2s) and grid with timestamps: ffmpeg -ss T -frames:v 1 + drawtext + tile=5x4
# Loudness: ffmpeg -i in.mp4 -af ebur128 -f null -   -> all IG reels measured -14.1..-14.8 LUFS
```
